## 왜 기록하는가

공부한 내용은 당일에는 선명하지만 시간이 지나면 쉽게 흐려진다. 이 블로그는 새로 배운 개념, 문제를 해결한 과정, 다시 설명할 수 있어야 하는 내용을 짧고 정확하게 남기기 위한 공간이다.

## 운영 방식

- 하나의 글에는 하나의 주제만 담는다.
- 문제 상황, 시도한 방법, 최종적으로 이해한 내용을 구분한다.
- 완벽한 글보다 다시 읽을 수 있는 기록을 우선한다.

## 첫 번째 목표

Next.js와 Vercel을 사용해 최소한의 기술블로그를 만들고, 글은 `content/posts` 폴더의 MDX 파일로 관리한다. 데이터베이스 없이 Git으로 글의 변경 이력을 남기는 방식부터 시작한다.

```tsx
export default function Note() {
  return <p>오늘 이해한 것을 내일 다시 설명할 수 있도록.</p>;
}
```
